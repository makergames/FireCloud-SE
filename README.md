## 🔥 Introducción

**FireCloud SE (System Edition)** es, probablemente, el primer sistema operativo visual nativo en navegador. 

Después de bastante tiempo de desarrollo —y bastantes dolores de cabeza—, **no me detuve**. Preferí seguir adelante a pesar de todas las dificultades técnicas. Miles de pruebas, tests, y un montón de problemas después, conseguí crear una versión más o menos estable.

No digamos que tenga una gran velocidad ni mucha potencia todavía... pero es útil para el día a día.

## 📜 Historia del proyecto

FireCloud no fue un proyecto nada fácil. Lleva **3 años en desarrollo** y tuvo muchas etapas previas.

### 🦴 El esqueleto — Maker OS

Resulta gracioso ahora, pero el primer prototipo fue hecho en **Genially**. Se llamaba **Maker OS** y era una versión esquelética, solo para hacerme una idea de cómo quedaría el proyecto final.

### 🧪 Cientos de versiones previas

Luego se empezaron a hacer versiones en **HTML, JS y CSS**, usando **WebAssembly**. Aunque no terminaron de gustarme del todo, se hicieron **cientos de versiones** para llegar al producto final. Se usaron **decenas de bibliotecas** que apenas entendía antes. 😅

### 🔥 El presente — FireCloud SE

Después de todo ese camino, FireCloud SE es el resultado. Un OS visual, funcional, open source, y con una comunidad por delante.
